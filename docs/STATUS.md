## 操作

- `W / S`:蹬车 / 刹车(低速可倒退)
- `A / D`:左右转向(D 屏幕向右)
- `Shift`:疾驰
- `Space`:跃起;**1.2 秒内连按三次起飞**;飞行中按住上升,松开缓降;再连按三次收翼
- 飞行时 `S`:俯冲下降
- `M`:静音
- `Esc`:退出本局回到标题

触屏:左下摇杆推拉控制油门/转向;右下「疾」按住加速、「降」按住俯冲、「跃」点按跳跃、连点三次起飞/收翼、飞行中按住上升。横屏体验最佳。

## 调试参数

| 参数 | 作用 |
|---|---|
| `?debug=1` | 性能面板 + `window.__qianli`(bike/world/scoring,便于 CDP 测试) |
| `?autostart=1` | 跳过标题直接开始 |
| `?reveal=1` | 所有区域强制上色,用于查看最终画面 |
| `?auto=1` | 自动骑行(拾光点→交付),用于回归测试 |
| `?seed=42` | 指定世界种子,布局可复现 |
| `?outline=0` / `?backdrop=0` | 关闭地形描边 / 远山视差壳 |
| `?touch=1` | 在桌面强制显示触屏控件,便于调试/回归 |

## 已知问题 / 后续

- 多人、NPC、服务端排行榜不在首版;部署待定(Vercel 后续考虑)
