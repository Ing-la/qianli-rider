# 设色千里 (Qianli Rider) — 文档索引

青绿山水题材的网页骑行游戏原型:在程序化生成的《千里江山图》风格长卷中骑行,收集石青/石绿/赭石颜料光点,送到亭台后让区域逐渐上色。

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck
npm run build
```

操作:`W/S` 蹬车刹车,`A/D` 转向,`Shift` 疾驰,`Space` 跃起(**1.2 秒内连按三次起飞**,飞行中按住上升、松开缓降、按 `S` 俯冲、再连按三次收翼),鼠标按住画面拖拽转视角,`M` 静音,`Esc` 退出本局。

手机:同一 Wi-Fi 下运行 `npm run dev`,打开 Vite 打印的 `Network` 地址(如 `http://192.168.x.x:5173`)。触屏操作:左下摇杆骑行,右侧「视角」盘转镜头,右下「疾/降/跃」;「跃」连点三次起飞,飞时按住上升、按住「降」俯冲。建议横屏。桌面可用 `?touch=1` 预览触屏界面。

调试:`?debug=1` 性能面板;`?autostart=1` 直接开局;`?reveal=1` 全图强制上色;`?auto=1` 自动骑行回归测试;`?seed=42` 固定布局;`?model=1` 模型检视(可加 `?wings=1`);`?overview=1` 高空俯瞰山丘地图;`?touch=1` 预览触屏控件。地图为约 1120×1120 m 的开阔草甸,散落 26 座可骑山丘,五座亭台位于前五座山顶。

## 目录约定

- `src/` — 游戏源码(按 core / world / render / bike / game / ui 分层)
- `docs/` — 本套文档,长期维护,是项目状态的事实来源
- `temp/` — 调研缓存、参考站逆向产物,可随时清理,不参与构建
- `public/` — 静态资源;可选放置 `scroll.webp`(用户自行提供的公版扫描件)
